# UI workspace

Workspace aislado para la libreria UI y su playground local.

## Estructura

- `package/`: libreria de componentes UI.
- `example/`: app de ejemplo para probar la libreria localmente.

## Uso

```bash
npm install
npm run dev
```

Comandos utiles:

```bash
npm run dev
npm run build
npm run build:package
npm run build:example
```
